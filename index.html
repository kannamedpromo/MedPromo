⚡ Quick Start Guide
  1. Go to Products → Add your medicines with specialty tags
  2. Go to Promo Sets → Create sets for each doctor/specialty
  3. Go to Present → Launch a full-screen visual presentation
📱 Install MedPromo as App

On your Samsung tablet: open this file in Chrome, tap the menu (⋮) → "Add to Home screen". MedPromo will appear as an app icon — tap it to open instantly, full-screen, like a native app. No internet needed after that.
